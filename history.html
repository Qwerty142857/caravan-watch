What's in each file

One row per caravan for sale that month.

make, model
Manufacturer and model, e.g. Willerby Malton
name
The advert's own title – only filled in when it says more than the make and model
dimensions
Length x width in feet
bedrooms, year
Number of bedrooms and the year the caravan was built
price
Asking price in pounds
park
The park as the website named it
canonical_park
The same park under its standard name, so one park is counted once whichever site listed it
postcode
The park's postcode
location
Town or county the website gave – only filled in when it adds to the park name
source_site
The website the caravan was listed on
is_twin
Y for a twin unit (16ft wide or more)
availability, property_type
As given by the few websites that show them
We will aim to collect data monthly from public caravan listings.
